# Arman Landing Page — Responsive on Mobile

A Persian RTL landing page for a fictional smart solutions company, built with HTML5, CSS3, and Bootstrap 5.

## Overview

This project is a modern company landing page designed for **Arman Smart Solutions**.

It features a clean layout, blue-themed design, Persian typography, interactive navigation menus, and a responsive layout for mobile devices.

## Features

- Persian RTL layout
- Responsive mobile design
- Mobile navigation menu
- Nested dropdown navigation menus
- Hero section with call-to-action buttons
- Clients and company statistics sections
- Services showcase
- Company introduction section with video
- Portfolio and project showcase
- Contact section
- Footer with company information
- CSS animations and hover effects
- Smooth scrolling

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome

## Responsive Design

The layout adapts to mobile screens using CSS Media Queries.

The mobile layout includes:
- Collapsible navigation menu
- Responsive hero section
- Adjusted content alignment and spacing
- Flexible service cards
- Mobile-friendly footer
- Optimized project showcase
